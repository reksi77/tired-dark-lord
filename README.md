A 100-word monologue for a fantasy villain who is secretly just very tired: the keeper of a toll bridge who has collected the same toll — one true story, told standing in the rain — for sixty years. The tiredness lives in the ritual, the short sentences and the small deflections, never in a plain statement. The sting lands in the last line: knock twice — once for the villain you expect, twice for the man who kept the bridge.

## Run it

```sh
node main.ts
```

This writes the monologue to `/output/entry.txt` (100 words, 513 characters) and validates the gate first: 1–600 characters, not only whitespace, 98–102 words, and none of the banned stock phrases.
